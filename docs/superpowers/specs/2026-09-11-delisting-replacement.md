# 退市公告退出与替补

用户已确认：正式终止上市决定首次公开触发退出；公告可知后的首个可成交交易时点卖出；仅日期证据从下一交易日起；卖出后用当日及以前数据重新运行当前规则，下一交易日尝试买入未持有的最高排名合格股票；仅花费卖出净回款，整手与费用约束保留，无候选则持有现金。旧产物不改写。

范围限定 8787 股票研究向导。冻结事件来源、时间精度、交易记录和替补评分截止日。行情继续后复权，金额/股数以原始开盘价为锚。无法核实公告不反推日期；停牌不伪造成交；日线仅作为成交模型，封死价格时不保证成交。新增持仓缺数据应报告实际股票和日期，不能因未来覆盖优劣选择替补。

实现新增事件模块与逐日记账模块；复用现有 fixed_v0 评分器，必须使用换仓时截面，不复用 FrozenRulePlugin 的初始排名。界面可选择原买入持有或公告退出替补，解释规则和结果。只有完整估值才输出完整收益；保留真实无法退出的未结算状态。

实现裁定：替补范围保留原研究信号日冻结的股票池，不引入研究范围外新上市股票；每次排名仍按换仓时上市有效区间过滤。前复权存量行情仅在至少5个重叠交易日的全部OHLC舍入区间存在同一换算比例（按来源实际小数位精度构造区间，取全部区间交集）后换算为后复权，保存比例、残差、重叠日期与来源路径；无法验证时报错，不静默剔除。成交状态与现有readiness一致：正成交量或成交额及有效OHLC作为已交易证据；未知且无成交证据不视为停牌。

验证补充：供应商六位复权因子在除权段之间存在有限精度差异，重叠校验允许额外 1e-5 相对误差（0.001%），并限制可行比例区间宽度不超过 0.1%，在冻结证据中记录容差和残差。这是有界精度近似，不声称数学上完全相同。无法通过、缺少交易状态或所需交易日时直接补拉后复权；单独缓存，重试复用。新旧后复权拼接前校验至少5日重叠OHLC一致，禁止仅凭标签拼接。

公告来源当前仅包含已核实的正式事件及用户提供的有效扩展，并非全市场完整公告库。无公告证据不能凭摘牌日期提前卖出；到了已知退市边界仍有持仓时保留未结算，不输出虚构完整收益。日线一字行情采用保守不成交规则。
