# 按计算依赖检查历史资料，保留退市未结算持仓

用户要求解决历史行业资料与退市两项阻断，不修改研究股票池或日期。

## 原因与修复

向导无条件要求所有历史股票都有三级行业资料，虽然 fixed_v0 仅依赖行情、成交额、收益率与均线。本次以 required-fields-v1 收窄向导的检查：严格检查历史上市身份，缺少未使用的行业字段列为信息；行业权重约束在组合配置时只要求所选股票的历史一级行业。保留 listing-only 证据标签，不将当前行业快照伪装成历史，也不授予完整 PIT 的正向证据标签。通用 CLI 默认检查契约不变。

退市原来阻断整个研究。新增 retain-unsettled-v1：已验证退市且持有期间发生时允许继续，退市前行情缺口仍阻断；股份保留，研究结果为 UNSETTLED，不能将未知回收额当作零或将末次行情当作卖出。已知资产包括已实现现金及可估值的其他未退出资产，但不包含未知退市股份价值。完整收益、期末权益、回撤等指标为空，不生成不完整股票子集冒充全组合的净值曲线。所有持仓均退市时仍用冻结交易日历覆盖请求结束日。未结算持仓不收取虚构卖出佣金或滑点。

退市呈现口径已向用户列出选项；未收到另行选择时，按已说明的默认“保留未结算持仓”执行。未启用零回收假设场景。

## 验证

- 全量 alphalab 测试 274 项通过；后续针对行业约束范围与全部持仓退市等新增/调整的测试另外通过。
- 向导与审阅 UI 25 项通过，未结算结果不能显示“已全部清算”。
- 固定规则不需要历史行业可以执行；启用行业约束必须验证历史行业；未选中股票缺行业不影响已选股票约束。
- 退市前缺日线仍阻断；退市后不请求不存在的 A 股日线；保留股份，现金与已知资产可核对，总收益不伪造。

真实草稿复查结果另附机器可读证据。
