不建议继续统一补数，也不建议过滤所有未来停牌／退市股票以获得可运行结果。

推荐先修复检查性能和阶段语义，然后分别交付停牌执行支持与证券身份／复权核实；退市清算仍保留独立能力边界。单纯放宽检查最快，但会把不能交易的价格用于撮合；完整重建账户引擎覆盖更广，但超出当前优先问题。

## P0：检查进度与计算性能

现状：_inspect_raw 对每只股票重复对整表做 astype(str)/布尔过滤，末尾又把全部行转为 Python dict 后哈希；prepare 提交、工作线程验证、backend.prepare 可连续执行完整检查。页面依赖阶段更新时间显示已用时，长计算阶段会显得没有进展。具体耗时比例仍需 profiler 量化。

设计：

1. 行情按 symbol 一次分组，历史元数据一次建立索引；避免 S×N 级重复整表扫描。
2. 数据指纹采用确定排序、包含 schema／来源／值的分块哈希，避免全量 dict/JSON 驻留；固定版本，验证相同数据指纹稳定、数据变化必然失效。
3. 同一冻结需求内复用检查产物；执行前检查数据版本与来源身份，发生变化才重新计算。不能为性能删掉提交前数据一致性校验。
4. 检查本身进入异步任务，阶段拆为加载、校验元数据、逐股检查、生成修复计划。每批股票更新已完成/总数、心跳、耗时；检查循环支持协作取消。
5. 页面显示真实运行时长和最近心跳。心跳过期时标为“进度暂不可确认”，保留刷新／取消操作；不能把 CPU 活跃等同业务进度。

验收：在本次 4,906 只真实只读快照上记录优化前后时间与峰值内存；无数据改变时不连续进行多次全量检查；检查结果和候选排名一致；每批可取消、最长心跳间隔目标 5 秒（具体吞吐目标以基准测量确定）。

## P1：把停牌分阶段处理

引入独立的交易状态事实，保留原始空值；研究视图可将确认停牌量额解释为零成交，但不得写成真实补数或伪造成可成交行情。未知状态仍阻断并继续核实。

- 预热：已确认停牌不是源数据损坏。明确 fixed_v0 的日历窗口、流动性均值分母及有效交易样本数；若策略按市场交易日计均值，停牌贡献零成交；不满足最小有效样本的股票作为当时规则不合格，记录原因。该行为必须版本化，不能悄悄改变旧运行。
- 信号：使用信号日及以前可知状态判断资格；不得根据未来停牌决定入选。明确当前停牌是否构成选股过滤条件并冻结规则版本。
- 建仓：002186 应产生“建仓日停牌、买入未成交”事件。推荐预定权重资金保留现金，其他股票不自动加权、不自动替换、不推迟该股建仓；实际成交股票数须满足 min_holdings，否则组合不可执行。
- 持有：已持有股票停牌期间禁止成交，净值使用最近可靠估值并标注陈旧天数；不可将用于估值的前值当作新的成交报价。跨分红送转的持仓／估值需与既有价格口径一致。
- 退出：结束日停牌则标记“未能退出、未实现持仓”，分别展示估值净值与已实现收益；正式的全额清算结果不可宣称已完成。

本阶段修改候选资格及成交／估值契约，必须先新增反例回归，再实现；与上一轮只改修复流程的范围不同。

## P1：来源不可满足的复权请求

对 302132 的修复记录存储 requested_adjustment 与 returned_adjustment。来源重复返回不支持口径时归类“来源不支持／身份待核实”，停止将其当成普通下载缺口。

交互提供：查看原始响应、重新核实证券身份、配置另一个可信来源、查看缺失复权因子的说明。只有用户明确选择新的探索样本范围才可排除标的，并在结果记录选择偏差；禁止自动绕过。

验收：请求 hfq 返回 none 不会覆写有效缓存；重复请求不改变标签；证券身份和复权因子满足前不可释放正式门禁。

## P2：退市与完整 PIT

退市清算需要独立数据契约：最后交易日、退市生效日、可用清算／回收事件、现金入账日期及来源。证据不足继续阻断正式清算，可另设明确标记的情景分析，但不能冒充真实回测。

历史行业应从具有生效区间的数据源补齐。来源配置页区分“历史上市状态可用”和“历史行业不可用”；若因子不使用行业而用户也未配置行业约束，未来可设计单独的无行业研究契约，但不能直接降低当前正式模式承诺。

## 页面建议

顶部先显示研究级阻断（PIT、入选股票建仓不可成交、退市），再显示候选池诊断。红色只表达会阻止当前研究继续的事项；已确认且规则支持的预热停牌用说明或黄色提示，未知状态保留待核实，下载失败单列。

摘要同时展示“股票数／股票交易日数／问题条目数”，避免 159 条误读为 159 只。关键持仓列表单独显示 002186 建仓停牌、002336 退市；不要让这些问题埋在几千只逐股卡片中。

明确区分任务完成、数据已解释、研究可执行三个结果。例如“已确认 53 个停牌日，仍有建仓与退市限制”，不能写成“53 个数据问题已修复，可回测”。
